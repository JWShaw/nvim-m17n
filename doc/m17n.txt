1. INTRODUCTION                                        *m17n-introduction*

nvim-m17n lets you type transliterated Latin and have it converted to another
script (Cyrillic by default) according to an m17n `.mim` input method file.
The conversion happens while you type.  Motion and editing commands are
unaffected, although — as with Vim's built-in keymaps — the character
arguments of commands such as `r` and `f` go through the input method while it
is on. >

    privet    -> привет
    shchuka   -> щука
    yolka     -> ёлка
<
The input method is enabled per buffer and can be toggled at any time.

==============================================================================
2. SETUP                                                      *m17n-setup*

Put this plugin on 'runtimepath' and optionally call: >

    require("m17n").setup({
      mim = "ru-translit",
    })
<
Calling `setup()` is optional; the defaults are used otherwise.  The bundled
input method is `mim/ru-translit.mim`.

==============================================================================
3. COMMANDS                                                *m17n-commands*

:M17nToggle                                            *:M17nToggle*
        Toggle the input method for the current buffer.

:M17nEnable                                            *:M17nEnable*
        Turn the input method on for the current buffer.

:M17nDisable                                          *:M17nDisable*
        Turn the input method off for the current buffer.

:M17nStatus                                            *:M17nStatus*
        Print whether the input method is on.

:M17nReload                                            *:M17nReload*
        Re-read the configured `.mim` file and reinstall mappings.

:M17nSetMim {name-or-path}                            *:M17nSetMim*
        Use another `.mim` file.  `{name-or-path}` is either the name of a
        file in `mim/` on 'runtimepath' (without the `.mim` extension) or a
        path to a `.mim` file.

In Insert mode you can also use the built-in |i_CTRL-^| to toggle the input
method, and |c_CTRL-^| in the command line.

==============================================================================
4. LUA API                                                *m17n-lua-api*

>lua
    local m17n = require("m17n")

    m17n.toggle([buf])   -- toggle; returns true when now enabled
    m17n.enable([buf])   -- enable for buffer (default: current)
    m17n.disable([buf])  -- disable for buffer (default: current)
    m17n.status([buf])   -- true when enabled
    m17n.reload()        -- re-read the .mim file
<
==============================================================================
5. OPTIONS                                                *m17n-options*

Configure with `require("m17n").setup({...})`.  Defaults: >

    {
      mim = "ru-translit",
      search = true,
      default_on = false,
      toggle_keymap = nil,
    }
<
`mim`~
        Name of a `mim/<name>.mim` file on 'runtimepath', or a path to any
        `.mim` file.

`search`~
        When true (default), search patterns are translated too: 'imsearch' is
        set to -1 (follow 'iminsert').  Set to false to keep typing `/`
        searches literal by setting 'imsearch' to 0.

`default_on`~
        When true, enable the input method automatically in every buffer.

`toggle_keymap`~
        Optional Insert-mode mapping that toggles the input method, e.g.
        `"<C-^>"`.  Default is nil because Neovim's built-in |i_CTRL-^|
        already toggles it.

==============================================================================
6. HOW IT WORKS                                        *m17n-how-it-works*

Language mappings (|:lmap|) are Neovim's built-in multi-key input engine: they
support multi-character sequences and "dead key" prefixes where Neovim waits
for the next key before deciding.  This plugin parses the `.mim` file into
buffer-local `:lmap` mappings and enables them via the 'iminsert' option.

`'iminsert'` is also used by the character arguments of single-character
Normal-mode commands such as `r` and `f`, and by search (through 'imsearch').
Those therefore use the input method too while it is on — the same behaviour as
Vim's built-in keymaps.  Search follows the input method by default; set the
`search` option to false to keep it literal.

==============================================================================
7. LIMITATIONS                                          *m17n-limitations*

Only static transliteration `.mim` files are supported: a single `(map ...)`
mapping key sequences to plain output, driven by a lone
`(state (init (map)))`.

Stateful input methods are NOT supported.  They use multiple states,
variables, candidate lists and commands such as `select`, `shift`, `set`,
`delete`, `move`, `undo`, `cond` and `include`, which cannot be expressed as
static key-to-output mappings.  Examples include the Chinese methods
(`zh-pinyin`, `zh-zhuyin`, `zh-cangjie`, ...), most Indic methods
(`hi-*`, `bn-*`, `gu-*`, `kn-*`, `ml-*`, `te-*`, `ta-*`, `si-*`, ...), the
Vietnamese methods (`vi-telex`, `vi-vni`, `vi-viqr`, ...), Tibetan `bo-*`,
Thai `th-*` and Japanese `ja-anthy`.  For those, use a full input-method
framework such as fcitx5 or ibus, which run the real m17n engine.
